# DirHunter

**DirHunter** — это легковесный и высокопроизводительный инструмент для фаззинга веб-директорий и поиска скрытых конечных точек , забытых резервных копий и утечек конфигурационных файлов на веб-серверах. 

Инструмент написан на Python с использованием асинхронной парадигмы, что позволяет ему отправлять тысячи HTTP-запросов в секунду, оставаясь при этом бережным к ресурсам системы и сетевому интерфейсу.

## Особенности
- **Максимальная скорость:** Использование библиотеки `aiohttp` и неблокирующего ввода-вывода делает сканер в десятки раз быстрее классических синхронных аналогов.
- **Контроль ресурсов:** Строгое ограничение конкурентности через комбинацию `asyncio.Semaphore` и `aiohttp.TCPConnector`.
- **Отказоустойчивость:** Автоматическое игнорирование таймаутов, ошибок SSL-сертификатов (важно для корпоративных стендов) и потери пакетов без прерывания общего сканирования.
- **Фильтрация шума:** Обработка только значимых HTTP-кодов (200, 204, 301, 302, 307, 401, 403) и скрытие ложных срабатываний (404).

## Установка

Для работы скрипта требуется Python 3.8+ и библиотека `aiohttp`.

```bash
git clone [https://github.com/](https://github.com/)[ТВОЙ_НИК]/AioDirHunter.git
cd AioDirHunter
pip install aiohttp
```

## Использование

Утилита принимает целевой URL, путь к текстовому словарю и количество одновременных потоков (по умолчанию 50).
```bash
python main.py -u http://127.0.0.1:8000 -t 50 -w wordlist.txt 
```
## Доступные аргументы:

- **-u, --url** — Целевой адрес веб-сервера (обязательный аргумент).
- **-w, --wordlist** — Путь к файлу со словарем путей `.txt` (обязательный аргумент).
- **-t, --threads** — Лимит одновременных подключений/задач (по умолчанию: 50).
